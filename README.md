# RAG-ассистент с логированием и метриками

Telegram-бот на базе RAG (Retrieval-Augmented Generation) с полным циклом
логирования: каждый запрос пользователя фиксируется в SQLite, доступна
статистика и экспорт логов в CSV.

## Метрики из реальной работы

| Метрика | Значение |
|---|---|
| Документов в базе знаний (ChromaDB) | 8 |
| Запросов обработано | 7 |
| Отвечено из кеша | 2 (мгновенно, без обращения к LLM) |
| Среднее время ответа | ~3,5–3,8 с |
| Уникальных пользователей | 1 |

## Что умеет

- Отвечает на вопросы по базе знаний (RAG: ChromaDB + OpenAI embeddings + GPT)
- Кеширует ответы — повторный вопрос обслуживается мгновенно и бесплатно
- Логирует каждое взаимодействие: вопрос, ответ, user_id, источник,
  время ответа в мс, признак «из кеша»
- Команды бота: `/start`, `/help`, `/stats` (статистика), `/logs` (личные логи в CSV)
- Три режима запуска: интерактивная консоль, демонстрация, Telegram-бот

## Стек

Python 3 · OpenAI API · ChromaDB · python-telegram-bot · SQLite

## Запуск

```bash
pip install -r requirements.txt
cp env.example .env   # вписать OPENAI_API_KEY и TELEGRAM_BOT_TOKEN
python main.py        # выбрать режим: 1 — консоль, 2 — демо, 3 — бот
```

## Безопасность

- Секреты хранятся в `.env` (исключён из git через `.gitignore`)
- В логах — только технический user_id, без персональных данных
- Пользователь получает через `/logs` только свои логи
